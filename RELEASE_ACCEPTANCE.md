# v0.1.5 — external acceptance checklist

**Testing candidate, not a stable release until these checks pass.**

- [ ] Test an installed skill in at least one supported coding/AI agent using an owner-consented résumé.
- [ ] Test a second environment using a reviewed pinned GitHub source + prompt (when capable).
- [ ] Check facts, dates, companies, metrics, awards, and private data against the source résumé.
- [ ] Generate two completely original themes, each with meaningful named SVG landmarks and coherent art direction.
- [ ] Verify that all illustrated landmarks open their intended panels with pointer, touch and keyboard.
- [ ] Verify no document scrolling and no clipping on desktop, small phone and landscape mobile.
- [ ] Check the accessible location list and recruiter/print view.
- [ ] Run local validator, browser tests and review screenshots for polish.
- [ ] Verify an **offline** generated portfolio opens without network resources.
- [ ] Prepare a GitHub Pages bundle with fictional data; confirm valid Open Graph metadata and preview image.
- [ ] Verify the CLI refuses public upload without owner approval and never overwrites an existing remote repository.
- [ ] Test an approved user-owned GitHub Pages deployment and a LinkedIn link preview, or mark these unverified.
- [ ] Review README, compatibility table, installation instructions and release ZIP checksums.

**Record each external result:** host & version, résumé type (non-identifying), requested theme, success/failure, fixes needed, whether link-only or installed, browser sizes, and any unsupported capabilities. Never publish actual résumé or private reports. Do not claim results not recorded.
