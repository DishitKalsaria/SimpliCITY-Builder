# Changelog

## v0.1.5 — Release candidate (external testing pending)

- Optional opt-in GitHub Pages publication bundle with local social preview screenshot, correct Open Graph/Twitter-card metadata, and editable LinkedIn draft.
- Optional authorized `gh` deployment to a *new* user-owned repository; fails closed without explicit public approval and never overwrites existing repositories.
- Lean README, up-to-date installation and link-only instructions, publishing privacy checklist, external acceptance plan and source/skill checksum packaging.
- Retains current no-scroll interactive SVG landmarks, mobile scenes, image-assisted artwork, art-direction guidance, résumé evidence and UI quality tests.
- Adds publishing metadata, input validation and no-auto-publish regression tests. No LinkedIn API integration or automatic posting.

## v0.1.4 — Quality testing candidate

- Improved art direction, optional image-assisted backgrounds, separate mobile compositions, SVG art kit and screenshot QA.
- Fixed duplicated SVG `class` attributes on animated landmarks and validation of sparse interactive shapes.
- CI hotfix: validator now counts actual SVG landmark classes instead of matching an exact HTML string.

## v0.1.3 — Landmark-first exploration

- Named and clickable SVG landmark objects replaced overlay pins.
- Added link-only retrieval guidance, social metadata options and mobile accessibility checks.

## v0.1.2 — Full-screen world navigation

- No-page-scroll, mobile layout and accessible location list.
- Rich résumé highlights, metrics, attributed quotes and review safeguards.

## v0.1.1 — Earlier prototype baseline

- Initial open-ended résumé-to-world generator and examples.
