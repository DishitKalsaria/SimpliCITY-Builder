# Contributing to SimpliCITY Builder

Thanks for considering a contribution. Please open an issue for larger features and include the intended user workflow before starting. Small bug fixes can go directly to a pull request.

1. Work on a branch and keep changes focused.
2. Run `python3 -m unittest discover -s tests -v`.
3. Generate at least one preset and one original theme demo, then check links, search and dialogs on mobile and desktop.
4. Use fictional résumé data in tests and screenshots. Never commit real private CVs, API keys or personal contact information.
5. Explain what changed, how it was tested, and any relevant limitations in your pull request.

Important principles: any imaginative theme; real résumé facts only; offline-first generated HTML; accessibility; zero forced user setup to *view* results; no surprise publishing or tracking. External images require licensing review; avoid dependencies unless they materially improve outcomes.

By contributing, you agree your contribution is provided under the repository's MIT License.
