# Curated SVG artwork primitives (v0.1.4)

Reusable **inspiration**, not a list of allowable themes. All art is created as original, local geometry with simple gradients and named clickable object groups. Adapt silhouettes, proportions, palette, light direction and landmark ID to fit the user's world.

- `space-desktop.svg` and `space-mobile.svg` — complete original three-location compositions (planet, spaceport, constellation) with matching landmark section IDs.
- `windmill.svg` — recognizable foreground landmark with layered rural setting.
- `crystal-spire.svg` — a dimensional magical crystalline tower.
- `ocean-creature.svg` — an original aquatic creature with large hit target.

These examples use `landmark-projects` as a placeholder for single-landmark snippets. Replace it with the section ID in the portfolio schema; do not duplicate IDs when combining into a single scene. A complete scene must have all career section landmarks and no repeated gradient IDs. Run `check_artwork.py`, `build_portfolio.py`, and Chromium browser QA. Respect reduced-motion preferences. No fonts, stock images or external assets are embedded.
